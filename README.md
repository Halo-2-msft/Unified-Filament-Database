# Unified-Filament-Database

A multi-brand 3D-printing filament reference catalog: one Excel workbook per brand, a combined master index, and a narrative guide (`filament_expert_guide_complete.md` / `.pdf`). Workbooks are generated by the `generate_*.py` scripts; `master_index.py` combines them.

## Recording sources (convention from 2026-11-02)

When a catalog entry is added or changed from a web page, end its `notes` field with the exact page address:

```
| Source: https://example.com/the/page (consulted 2026-11-02)
```

Several pages go in the same tag, separated by `; `. This is what lets the guide's Part 25 (Sources and Credits) credit the exact page, not just the site. Entries written before this date record only the site name and date.

Run `python3 check_sources.py` to list any entries dated on or after the cutoff that are missing a Source URL. It is a reminder, not a gate.
